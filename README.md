# FlowAI

FlowAI is a single-page SaaS landing page concept for an AI productivity assistant. It is built with semantic HTML, CSS, and small vanilla JavaScript enhancements.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

The product, companies, testimonials, and pricing shown are fictional portfolio content.
