# 网站开发 Portfolio

这是一个个人网站开发 Portfolio，用于展示企业官网、个人网站、品牌落地页和服务型网站案例，并承接网站制作需求。

## 技术

- HTML5
- CSS3
- Vanilla JavaScript

## 本地预览

可直接打开 `index.html`，或运行静态服务器：

```bash
python3 -m http.server 8000
```

## 部署

项目可直接部署到 Vercel 等静态托管平台。
